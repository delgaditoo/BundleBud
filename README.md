# AI File Organizer (MVP)

## Run (Dev)
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Troubleshooting
- If Electron launches but no window: ensure the Vite dev server is running at http://localhost:5173.
- If Electron fails to launch with a Node-mode error, ensure `ELECTRON_RUN_AS_NODE` is not set.
- Reports are stored in the app data folder under `reports/`.
